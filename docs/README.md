# Diario Alimentario

Aplicación Android Flutter local-first para registrar alimentos, comidas y reacciones.

## Tecnologías

- Flutter y Dart
- SQLite mediante Drift
- Material Design 3
- Almacenamiento privado local

## Ejecución

```powershell
flutter pub get
dart run build_runner build
flutter run
```

La aplicación no requiere Internet ni autenticación.
