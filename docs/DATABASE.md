# Base De Datos

La base SQLite se guarda como `diario_alimentario.sqlite` en el directorio privado de la aplicación.

Tablas principales: `categories`, `foods`, `meals`, `meal_foods`, `symptoms`, `reactions`, `reaction_symptoms`, `reaction_photos`, `app_settings` y `schema_metadata`.

La versión inicial es `schemaVersion = 1`. Los archivos generados por Drift no deben editarse manualmente.
