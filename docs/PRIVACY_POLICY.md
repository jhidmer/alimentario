# Política De Privacidad

**Última actualización: 29 de septiembre de 2026**

Diario Alimentario es una aplicación local-first. No requiere cuenta y no envía comidas, síntomas, reacciones, fotografías ni estadísticas a servidores externos.

## Datos almacenados

La aplicación almacena localmente alimentos, comidas, síntomas, reacciones, fotografías opcionales, preferencias y copias de seguridad creadas por el usuario.

## Uso

Los datos se utilizan exclusivamente para registrar información personal, mostrar historial, calcular estadísticas y calcular asociaciones temporales dentro del dispositivo.

## Fotografías y cámara

La cámara y el selector de imágenes se utilizan únicamente cuando el usuario solicita agregar una fotografía a una reacción. Las fotografías se guardan en el almacenamiento privado de la aplicación.

## Compartición

La aplicación no vende ni comparte datos con terceros. Si el usuario utiliza las funciones de compartir CSV, PDF o backup, el archivo se entrega al destino que el usuario seleccione mediante el sistema operativo.

## Eliminación

El usuario puede eliminar registros individuales o todos los datos desde Configuración. La eliminación total requiere doble confirmación.

## Salud

La aplicación no es un dispositivo médico y no diagnostica, trata, cura ni previene ninguna enfermedad. Las asociaciones son coincidencias estadísticas y no demuestran causalidad. Consulte a un profesional de la salud para orientación médica.
