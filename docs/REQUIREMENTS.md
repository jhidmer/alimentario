# Requisitos

La funcionalidad principal debe operar offline y mantener los datos en el dispositivo.

El sistema no realiza diagnósticos ni afirma causalidad. Las asociaciones temporales son coincidencias estadísticas.

## Registro rápido

RF-016: el usuario podrá crear un alimento desde el formulario de comida.

RF-017: el alimento recién creado quedará seleccionado automáticamente.

RF-018: crear un alimento no deberá borrar la fecha, hora ni selección actual de la comida.
